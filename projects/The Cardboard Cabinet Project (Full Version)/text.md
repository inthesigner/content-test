# The Cardboard Cabinet Project (Full Version)
The Full Size Version is the most ambitious iteration of the cardboard arcade cabinet project, designed to recreate the experience of a classic arcade machine on a larger scale. Unlike the smaller versions, this cabinet is built for two players, with a dedicated control area for each one.

The control panel features two arcade joysticks and six action buttons per player, following the layout commonly found in traditional arcade fighting and action games. This configuration allows for a wider range of games and makes the cabinet suitable for multiplayer experiences, encouraging direct interaction and competition.

The structure is made primarily from cardboard, exploring how an inexpensive and easily accessible material can be used to build a large-scale object with functional and ergonomic requirements. Particular attention must be paid to the proportions of the cabinet, the positioning of the controls, the rigidity of the structure and the integration of the display and internal hardware.

More than simply building a larger version of the same machine, the Full Size Version represents an opportunity to investigate the design and construction of a complete arcade cabinet. It combines physical prototyping, electronics, software and collaborative work to transform a simple material into a fully playable two-player gaming system.
